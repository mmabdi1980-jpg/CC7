# CC7
## Image Gallery

A **responsive grid-based image gallery** designed to display images neatly across different screen sizes.

* **Grid Layout** — Organizes images into clean, structured columns.
* **Responsive Design** — Adapts smoothly to mobile, tablet, and desktop screens.
* **Hover Effects** — Adds interactive visual effects when users hover over images.
* **Clean Presentation** — Provides an attractive and user-friendly gallery layout.
